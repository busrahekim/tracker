# Tracker

A lightweight, TypeScript-first personal tracker for time, habits, and activity logging.

Tracker helps you record, visualize, and review activities so you can improve focus and productivity. Built with TypeScript and designed to be simple, fast, and easy to extend.

## Features
- Quick activity/time logging
- Customizable categories or habits
- Simple dashboard for recent activity and basic stats
- Export/import data (JSON/CSV)
- Extendable TypeScript codebase for adding new views and integrations

## Getting started

Prerequisites
- Node.js 18+ and npm or yarn
- (Optional) A database or storage backend if the project uses one — see project configuration

Install
```bash
# install dependencies
npm install
# or
yarn install
```

Run (development)
```bash
npm run dev
# or
yarn dev
```

Build
```bash
npm run build
# or
yarn build
```

Test
```bash
npm test
# or
yarn test
```
